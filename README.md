# Workflow

A CLI tool to help you stay focused within the terminal

# How to Run
1. Install Java (https://www.java.com/en/download/)
2. Whenever you want to lock in, run java Main.java

# Algorithm
1. Loop until the user says “STOP”
    1. Loop twice
        1. Ask the user for the next task to work on from the list
            1. If the input is “STOP”, end the loop 
        2. Run a 15 min timer (sleep)
            1. Print the time remaining every 5 minutes
            2. Print a message when the timer finishes
    2. Start a 15 min break timer
        1. Print the time remaining every 5 minutes
        2. Print a message when the timer finishes
